Template Variables

                    

                        Templates support the following variables:

                        {title} - Diagram title

                        {description} - Description text

                        {mermaid_diagram} - The Mermaid diagram code

                        {jira_ticket} - Jira ticket key

                        {jira_url} - Full URL to Jira ticket

                        {diagram_description} - HTML description of the diagram

                        {date} - Current date

                        And more depending on the template type.
